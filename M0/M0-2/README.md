## YAML 配置格式

最小配置示例：

```yaml
input_csv: "sample_data.csv"

columns:
  x: "sensor_a"
  y: "sensor_b"
```

| 配置项 | 含义 |
| --- | --- |
| `input_csv` | CSV 文件路径，可以使用相对路径或绝对路径 |
| `columns.x` | 第一列数据的表头名称 |
| `columns.y` | 第二列数据的表头名称 |

配置顶层和 `columns` 都应为键值结构，路径和列名应使用字符串。列名必须与 CSV 表头完全一致，包括大小写和空格。数字形式的列名也可以使用，例如 CSV 表头为 `123` 时，应在 YAML 中写成 `x: "123"`。

原示例配置还包含 `task.name` 和 `task.verbose`。当前代码没有读取这两个配置项；修改 `verbose` 暂时不会改变输出内容。

## CSV 输入格式

CSV 使用逗号分隔，第一行为表头。例如：

```csv
timestamp,sensor_a,sensor_b,note
0,1,2,a
1,2,4,b
2,3,6,c
```

输入要求：

- 必须包含配置中指定的两列表头；其他列不参与计算。
- 参与计算的两列至少有两组对应数据。
- 参与计算的单元格可以转换为浮点数，不允许空值、普通文本、`NaN` 或无穷大。
- 两列都必须存在变化；任意一列全部相同时，相关系数无定义。

## 计算方法

函数先检查数据数量、有限性和零方差，再进行计算。为减轻浮点运算中的溢出和精度损失，代码使用了以下处理：

1. 每列减去该列首项进行平移；平移不改变数值之间的差。
2. 如果平移产生非有限值，该列退回原数据，再继续缩放。
3. 每列除以其最大绝对值进行正比例缩放。
4. 使用 `math.fsum` 累加数据、偏差平方和与偏差乘积和。
5. 分别对两列的偏差平方和开方，再相乘得到分母。
6. 将均值还原到原数据的尺度后返回。

对每列分别平移或乘以正的比例因子，在数学上不改变皮尔逊相关系数。上述处理可以改善部分数值情况，仍然受浮点数可表示范围和精度限制。

核心计算逻辑手写实现；NumPy 用于结果对照。

## 输出含义

程序先打印自己的计算结果，再打印 NumPy 的结果：

| 输出项 | 含义 |
| --- | --- |
| `n` | 参与计算的数据对数，不包含表头 |
| `mean_x` | 第一列原始数据的均值 |
| `mean_y` | 第二列原始数据的均值 |
| `r` | 手写函数计算的皮尔逊相关系数 |
| `NumPy r` | `numpy.corrcoef(xs, ys)[0, 1]` 的结果 |
| `绝对误差` | 两种计算结果之差的绝对值 |
| `精度检查` | 结果均为有限值且绝对误差不超过 `1e-6` 时显示“通过” |

以上面的三行 CSV 为输入，`n` 应为 `3`，两个均值应接近 `2` 和 `4`，`r` 应接近 `1`。实际输出的末尾小数可能因浮点运算略有差别。

数学上，`r` 在 `[-1, 1]` 范围内：`1` 表示完全正线性相关，`-1` 表示完全负线性相关，接近 `0` 表示线性相关程度较弱。零相关不代表不存在其他关系，相关也不代表因果。

NumPy 同样使用浮点运算。遇到极端数据时，它的输出也可能失真或成为非有限值，不能把一次对照当作所有输入下正确性的证明。

## 异常处理

当前代码对以下情况提供中文错误提示：

- YAML 文件不存在、为空、只有注释或格式错误。
- 配置缺少 `input_csv`、`columns`、`x`、`y` 等必要键。
- CSV 文件不存在、为空，或缺少指定列。
- 指定单元格为空、无法转换为数字，或为非有限数值。
- 数据对少于两组，或某一列的方差为零。
- 直接调用计算函数时，两列长度不同或包含非有限数值。

主程序捕获的上述异常会打印提示，并以退出码 `1` 结束。计算函数直接向调用者抛出 `ValueError`，便于测试或其他程序处理。

## 单元测试

先进入虚拟环境，再从 `M0/M0-2` 目录运行：

```bash
source ~/smartcar-practice/.venv/bin/activate
cd ~/22SmartCar/M0/M0-2
python3 -m unittest discover -s tests -v
```

当前测试文件包含三个用例：

| 测试 | 输入 | 预期结果 |
| --- | --- | --- |
| 完全正相关 | `[1, 2, 3]` 与 `[2, 4, 6]` | `r` 接近 `1` |
| 完全负相关 | `[1, 2, 3]` 与 `[6, 4, 2]` | `r` 接近 `-1` |
| 零方差 | `[1, 1, 1]` 与 `[2, 4, 6]` | 抛出 `ValueError` |

前两个用例使用 `assertAlmostEqual(..., places=6)` 检查结果，第三个用例使用 `assertRaises(ValueError)` 检查异常。开发过程中已在本地运行这三个用例并通过。

正常应看到 `Ran 3 tests` 和 `OK`。若显示 `Ran 0 tests`，需检查文件是否保存、文件名和测试方法名是否符合发现规则；此时尚未完成实际测试。

主程序采用 `if __name__ == "__main__":` 入口保护。测试导入 `calculate_correlation` 时，不会自动读取 YAML、CSV 或打印主程序结果。
